# Java_Labsheet_1

BCA201P — Foundations of Java Development

This folder contains 10 Java programs selected from original questions 11–30, excluding questions 1–10. Each program has a corresponding sample output text file.

## Programs
1. Largest of Three Numbers
2. Leap Year
3. Positive, Negative, or Zero
4. Armstrong Number
5. Palindrome Number
6. Prime Number
7. Valid Triangle
8. Square or Rectangle
9. Profit or Loss
10. Simple Calculator

Compile and run a program with JDK 21 or higher. Example:
`javac Q01_LargestOfThree.java`
`java Q01_LargestOfThree`
